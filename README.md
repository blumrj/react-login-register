# React Login/Register

A minimal React TypeScript project demonstrating a simple authentication UI (login and registration) with simulated API responses. It's intended as a learning/sample app to show form validation, local storage usage, and basic auth flows.

## Features

- Login form with client-side validation
- Registration form with client-side validation
- Simulated API responses (success and error cases)
- Local storage helpers for persisting user data
- Reusable form components and notification/snackbar support

## Tech stack

- React
- TypeScript
- Vite
- Axios (for API calls)
- React Router
- React Hook Form
- Zod

## Purpose

I created this project to practice and demonstrate building a simple authentication flow with React + TypeScript, including handling API errors, form schemas/validation with Zod and React Hook Form, and local storage management. It's useful as a starter template for small apps or for learning state management and form handling patterns.
